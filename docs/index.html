What's new in v3.5

🩹

Launch crash fixed

The settings table loads in the background, so the search box could filter it before the first load finished and crash the app. The filter now waits for the data.

🔋

Boot crash fixed

Android 15 and 16 no longer allow a boot receiver to start this kind of foreground service. The scheduled boot actions now run directly from the receiver.

🤖

Android 15, 16 and 17 support

Targets API 34 so it installs everywhere, and reads and writes the system, secure and global tables through root or Shizuku.

🛡️

Privileged access

Root is used automatically. On non-rooted devices, start Shizuku and grant access from the overflow menu.

🎨

Material 3 design

A complete colour-role palette for light and dark, tonal cards, and edge-to-edge system bars.
